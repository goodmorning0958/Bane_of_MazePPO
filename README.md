# Bane_of_MazePPO
Bane_of_MazePPO is a small Maze-solving PPO Robot. This was used in a research study investigating if energy efficient robot navigation using PPO is still effective. We appreciate any ideas for improvement, as this is our first time building an AI.
v1.0.5 features basic physics, and trains on small mazes. We compared the robot's path with the A* algorithm, and analysed relationships between constraint amount and effectiveness.
